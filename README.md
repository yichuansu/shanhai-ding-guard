# 山海守鼎（Shanhai Ding Guard）

捕获异兽当塔的肉鸽塔防，题材取自《山海经》。九鼎崩裂，鼎上所铸的异兽逃散九州；玩家作为守鼎人沿路守鼎，把异兽收回鼎中，再让它们替自己守鼎。

仓库根目录就是 Godot 工程，用 Godot 打开根目录的 `project.godot`。

> 2026-11 之前的 Unity 版本已移除，需要时可从 Git 历史找回：最后一个 Unity 版本是提交 `f4aa7e7`（`git checkout f4aa7e7`）。

- 引擎：Godot **4.7.2**（GDScript，静态类型），渲染器 Compatibility
- 基准分辨率：1920×1080，`canvas_items` + `expand`，横屏
- 平台顺序：Windows / macOS / Steam Deck → iOS / Android

## 运行

```bash
# 以下命令都在仓库根目录运行
# 首次或改了 class_name 之后：导入工程，生成全局类缓存
godot --headless --path . --import

# 打开编辑器
godot --path . -e

# 无头测试
godot --headless --path . --script res://tests/run_tests.gd

# 平衡模拟：每张战场 × 每种双异兽阵容
godot --headless --path . --script res://tools/simulate_battles.gd

# 节奏报告：时长、剩余灵气、花费间隔、每杀命中、单次伤害等手感指标
godot --headless --path . --script res://tools/pacing_report.gd

# 整局模拟：自动玩家从开局打到首领，统计通关率和倒在哪里
godot --headless --path . --script res://tools/simulate_runs.gd
```

灰盒操作：

- 开局：选守鼎人和鼎劫等级（未解锁的守鼎人显示解锁条件和进度）。
- 路线图：点亮着的节点前进。墨绿线是走过的路，金线是接下来能走的。
- 战后：普通战三选一拿异兽，精英战三选一拿法宝，也可以跳过换贝币。阵容满了会先让你选一只放生。
- 集市：买异兽、法宝、镇鼎符、修鼎；可以免费放生。
- 炼鼎（一次）：两只同种同阶升一阶，或按五行相生配方融合出稀有异兽。
- 奇遇：《山海经》原文事件，二到三个选项，部分有风险。祭祀：修鼎或加固二选一。
- 图鉴：路线图底部"山海经图鉴"。每州一栏，加上相生炼成、首领；未遇见显示"？？？"，遇见未收服显示名字和五行，收录后显示原文、数值和特性。稀有异兽的两种原料都收录后才显示配方。
- 战斗：点下方阵容选中异兽，再点空鼎位部署（悬停可预览射程）。点已部署的异兽，右上角弹出"升级 / 收回"。
- 波次：左上角显示下一波的敌人和倒计时，可以"提前召唤"，剩余时间越多奖励灵气越多。
- 捕获：敌人血量低于捕获线（默认 25%）时出现金色"可收"圈，点它消耗镇鼎符。
- 技能：点顶部技能按钮，再点战场释放（金色圈是范围，右键取消）；射日不用选位置。
- 镇守型异兽（阵容按钮上标"镇守"）部署后，虚线连到它在路上的拦截点。

## 分层

```
scenes/   表现与输入（Node、绘制、HUD）      ──┐ 读状态、提交意图
autoload/ 局外流程（Game）与内容单例（Content） │
run/      一局：路线图、阵容、经济、存档字段    │
meta/     跨局：图鉴、统计、设置                │
sim/      守鼎战权威模拟（10Hz tick）         ◄─┘
content/  数据定义（Resource）与 .tres 内容
core/     随机流、时钟、五行关系、阵容实例
services/ 本地存档（以后加云存档）
```

依赖只能向下：

| 层 | 可以依赖 | 不可以依赖 |
| --- | --- | --- |
| `core/` | 无 | 其他所有层 |
| `content/` | `core/` | `sim/`、`run/`、场景 |
| `sim/` | `core/`、`content/` | Node、输入、渲染、`autoload/`、`run/` |
| `run/`、`meta/` | `core/`、`content/` | 场景、`autoload/` |
| `autoload/` | 以上全部、`services/` | 具体场景脚本 |
| `scenes/` | 全部 | — |

`sim/`、`run/`、`meta/` 都是 `RefCounted`，不进场景树，所以测试和平衡工具能在无头模式下直接跑。

## 关键约定

**确定性。** 所有随机都走 `RngStream`。一局一个主种子，路线图用 `map:<州>`、每场战斗用 `battle:<州>:<节点>` 派生子种子。同种子同操作必然同结果，这是每日挑战、问题复现和平衡模拟的基础。存档只保存种子和进度，路线图读档时重建。

**模拟与表现分离。** `BattleSim` 每拍按固定顺序推进（见文件顶部注释）。表现层只读公开字段，用 `queue_deploy / queue_recall / queue_capture` 提交意图，下一拍生效。`SimClock` 把墙钟换成 tick，倍速只改每帧跑几拍，不改单次结算。`BattleView` 用 `SimClock.alpha()` 在两拍之间插值。

**效果系统。** 异兽特性（"见则"）、五行阵、法宝、守鼎人被动都是 `EffectDef`（trigger + op + 参数 + 可选五行作用域）。目前支持的组合列在 `sim/battle_sim.gd` 顶部。新增效果：在那里加一个 op 的处理，然后在数据里引用，不写针对某只异兽的特例代码。

**守鼎人。** `KeeperDef`：开局阵容、开局镇鼎符、战斗内被动、一个主动技能（`SkillDef`：范围伤害 / 范围定身 / 打击最强）。技能消耗灵气、按 tick 冷却，以意图形式提交。

**镇守。** `BeastDef.guard_hp > 0` 的异兽部署后，在离鼎位最近、且不超过 `guard_reach` 的路径点拦截敌人，最多同时挡 `block_count` 只；被挡住的敌人每拍造成 `contact_damage`。生命归零后放行，`guard_recover_ticks` 拍后满血恢复。首领不会被挡。

**五行阵。** 场上同一五行的异兽达到档位数量（灰盒是 2 / 4）时，该阵的效果以"该五行"为作用域注册，只取达到的最高一档。阵名取自《尚书·洪范》：润下、炎上、曲直、从革、稼穑。

**单位。** 长度用 1920×1080 设计像素，原点左上。速度在数据里按"每秒"填写，模拟里除以 10。

**内容。** 数据以 `content/` 下的 `.tres` 为准，在编辑器 Inspector 里改。`tools/seed_graybox_content.gd` 只用于生成或重置灰盒数据，会覆盖同名文件。`ContentLibrary` 加载时校验 id 重复、引用缺失、出怪数量等问题，`test_content.gd` 会在 CI 里拦住坏数据。

**存档。** `SaveStore` 先写 `.tmp` 再替换，替换期间保留 `.bak`。`RunState` 和 `Profile` 都带 `schema`，版本不认识时返回 null 或空档案，不会读出半个坏档。

## 美术

方向是"古籍刻本 × 青铜拓片"，不用 Unity 版的 Q 版卡通美术。规格见 [docs/ART_SPEC.md](docs/ART_SPEC.md)，AI 出图工作流见 [docs/ART_PIPELINE.md](docs/ART_PIPELINE.md)。

| 工具 | 作用 |
| --- | --- |
| `tools/art/palette.py` | 项目色板的唯一来源（纸、墨、五行各三档、青铜） |
| `tools/art/export_palette.py` | 导出 Krita / GIMP 色板 `art_src/shanhai_palette.gpl` 和预览图 |
| `tools/art/make_prompts.gd` | 按原文生成每只异兽的绘图提示词 → `art_src/PROMPTS.md` |
| `tools/art/prepare_beast.py` | 去背景、裁边、统一 512×512、压到五行色板、加墨线外轮廓 → `art/beasts/<id>/body.png` |
| 开局界面"美术预览" | 不进战斗查看每只异兽的图和动作，对比战斗实际尺寸 |

## 一局的构成

一局依次经过冀州、青州两幕（`core/regions.gd`）。每州一张分支路线图，打完该州首领修复该州之鼎：冀州首领给法宝三选一，铜鼎回复一半已损失耐久，然后进入青州；打完青州首领通关。

| 州 | 五行 | 异兽 | 首领 |
| --- | --- | --- | --- |
| 冀州 | 土 | 当康、狸力、夫诸、毕方、化蛇、文鳐鱼、精卫、鸣蛇、朱厌（精英） | 相柳：毒涎定住最近两只异兽；血量 2/3、1/3 召出鼎煞 |
| 青州 | 木 | 軨軨、朱獳、獙獙、鵹鹕、絜钩、合窳、峳峳、蠪蛭（精英） | 蜚：行草则死（身边异兽伤害 -35%）、见则天下大疫（每 8 秒吸走 4 灵气）、血量减半召出可捕获的絜钩 |

首领漏到鼎前直接判负，不论铜鼎还剩多少耐久；首领血量只随州数放大，杂兵随路线图层数逐层变强。

| 节点 | 内容 |
| --- | --- |
| 战斗 / 精英 / 首领 | 守鼎战；胜利后普通战奖励异兽三选一，精英奖励法宝三选一 |
| 集市 | 3 只异兽（约 14 贝币）、2 件法宝（22–35）、镇鼎符 ×2（6）、修鼎 +3（8）、免费放生 |
| 炼鼎 | 一次：升阶，或融合（精卫 + 毕方 → 凤皇，鸣蛇 + 化蛇 → 应龙，当康 + 鸣蛇 → 驳，毕方 + 狸力 → 夔，軨軨 + 絜钩 → 句芒，峳峳 + 合窳 → 天吴） |
| 奇遇 | 7 个：青丘之狐、峚山玉膏、招摇祝余、帝台之棋、流波山之夔、迷穀之木、杻阳鹿蜀 |
| 祭祀 | 修鼎 +4，或耐久上限 +2 |

奖励池：图鉴里收录过的异兽和守鼎人开局异兽；不足 3 只时用全部普通异兽。稀有异兽只能融合得到。

图鉴记录（`meta/profile.gd`）：遇见过的异兽（含首领召唤物）、亲手捕获次数、通过奖励 / 集市 / 炼鼎 / 奇遇获得过的异兽、击败首领次数。收录 = 捕获或获得过；首领要击败才算。

法宝 7 件：河图、洛书、帝台之棋、迷穀、祝余、玉膏、鹿蜀皮，效果见 `content/relics/`。

首领相柳：每 9 秒喷毒涎定住最近的两只异兽 3.5 秒；血量降到三分之二、三分之一时各召出一批鼎煞；漏到鼎前直接失败。

难度：路线图每深入一层敌人血量 +12%，每进入下一州再 +20%；首领血量只随州数放大。按 `tools/simulate_runs.gd` 调到自动玩家（鼎劫 0 级）整局通关率约 47%：铸鼎匠 8/20、巫祝 11/20、羿裔 9/20。

## 守鼎人与鼎劫

| 守鼎人 | 开局 | 被动 | 技能 | 解锁 |
| --- | --- | --- | --- | --- |
| 铸鼎匠 | 毕方、狸力 | 镇守生命 +30%，全体伤害 +10% | 鼎鸣：范围 900 伤害 | 一开始可用 |
| 巫祝 | 精卫、化蛇 | 捕获线 +15%，每场 +1 临时镇鼎符 | 定身符：范围定身 5 秒 | 图鉴收录满 8 只 |
| 羿裔 | 鸣蛇、精卫 | — | 射日：打击生命最高的敌人 1200 | 击败一次相柳 |

平衡方法：`simulate_runs.gd -- --matrix` 做守鼎人 × 开局阵容交叉对照，分清强弱来自守鼎人本身还是开局阵容，再分别调整。

鼎劫 1–10 级（`meta/ascension.gd`），逐级叠加：敌人血量 +10% → 开局灵气 -3 → 铜鼎上限 -2 → 敌人移速 +10% → 集市价格 +25% → 每场最多 2 张镇鼎符 → 首领血量 +15% → 奖励只给两个选项 → 敌人血量再 +10% → 祭祀修鼎减半。每位守鼎人分开记录，在第 N 级通关解锁第 N+1 级。

## 手感与节奏

数值对照同类热门塔防的节奏（Kingdom Rush、明日方舟、Bloons TD 6 的通行做法），用 `tools/pacing_report.gd` 量化验证：

| 系统 | 做法 |
| --- | --- |
| 局内升级 | 每只异兽战斗中可升到 Lv.3，费用为部署费 ×2 / ×3.5；伤害 ×1.6 / ×2.4，射程 ×1.1 / ×1.2，镇守生命 ×1.5 / ×2.2。收回返还一半投入 |
| 灵气经济 | 开局 15，每秒 +1，击杀杂兵 +1、异兽 +3、精英 +6。部署 6–8 |
| 波次 | 普通战 5 波、首领战 6 波；第一波前 8 秒，之后每波前 15 秒倒计时；提前召唤每剩 1 秒奖励 0.5 灵气 |
| 数值 | 杂兵 280–420 血，普通异兽 1000–2100，精英 4800–6000，相柳 14000、蜚 18000；单次伤害 35–280，暴击 5–20%（鸣蛇 ×2.5，其余 ×2） |
| 攻击节奏 | 精卫快射 0.4 秒、毕方 / 镇守 0.8–1 秒、化蛇范围 1.5 秒、鸣蛇重击 2 秒 |
| 难度递增 | 路线图每深入一层敌人血量 +12%，每进入下一州 +20% |
| 打击感 | 伤害跳字（暴击大号黄字）、受击闪白和抖动、击杀爆散、开火后坐、捕获时墨点飞入鼎中、漏怪时鼎红闪加震屏、技能扩散圈 |
| 音效 | `tools/synth_sfx.py` 合成的占位音：命中、暴击、击杀、部署、升级（宫商角）、捕获（编钟）、漏怪（锣）、波次（鼓）、技能（磬）、胜负。换正式音效时替换 `assets/sfx/` 下的同名文件 |

## 字体

内置字体是子集。`test_content.gd` 会检查所有内容文字都在字体里，缺字时测试失败并列出缺的字，这时重新裁剪（源字体不入库，从 Google Fonts 下载 Noto Sans SC）：

```bash
pip install fonttools
python3 tools/subset_font.py <NotoSansSC-Regular.ttf> assets/fonts/NotoSansSC-Subset.ttf
```
