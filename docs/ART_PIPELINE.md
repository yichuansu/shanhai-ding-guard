# AI 美术工作流

适合不会画画、用 AI 工具出图的情况。目标：风格统一、轮廓清楚、能合法上架。交付标准见 [ART_SPEC.md](ART_SPEC.md)。

## 0. 先确认规则

- **Steam 要求披露 AI 生成内容。** 提交游戏时的内容调查问卷里如实填写"预先生成的内容"用了 AI，商店页会显示。如实披露可以上架，隐瞒的风险远大于披露。
- **版权。** 在美国，纯 AI 生成、缺少足够人工创作的图像目前不受版权保护；你的筛选、修改、组合越多，可主张的权利越多。国内法院有过因人工投入较多而认定 AI 图像受保护的判例。正式上线前建议咨询专业人士。
- **工具授权。** 用明确允许商用的工具或付费套餐；开源模型逐个确认许可证是否允许商用。
- **口碑。** 部分玩家反感 AI 美术。一眼能看出是 AI 的图会招差评，所以重点是风格统一、人工清理干净。Steam 主图（capsule）建议请人画或人工重绘。

## 1. 定风格（只做一次）

1. 收集公有领域的明清《山海经》刻本插图作参考（胡文焕本、汪绂本等）。
2. 用 `art_src/PROMPTS.md` 里任意一只异兽的提示词，配合参考图（工具支持"风格参考 / 图生图"就用上），生成几十张。
3. 挑出风格最好的 3–5 张作为**定调图**，存到 `art_src/style/`。之后所有异兽都对照它们。
4. 一致性是 AI 美术最大的难题。两种办法：
   - 工具自带的"风格参考"功能，每次都喂同一组定调图；
   - 用 20–40 张已认可的图训练一个风格模型（LoRA），之后生成都套用它。

## 2. 每只异兽

```
提示词 ──→ 生成多张 ──→ 挑一张 ──→ 清理 ──→ prepare_beast.py ──→ 游戏里看效果
```

1. **提示词**：打开 `art_src/PROMPTS.md`，复制对应异兽的那段。提示词按原文写了外观，统一要求刻本风格、朝右侧身、纯色纸背景、对应五行的配色。负面提示词在文件开头。
   内容改了以后重新生成：`godot --headless --path . --script res://tools/art/make_prompts.gd`
2. **生成**：每只出 8–16 张，挑最像原文、轮廓最清楚的一张。
3. **清理**（在 Krita 里，免费）：AI 常见的问题要人工改掉：
   - 结构错误：毕方只能有一条腿，相柳要九个头，驳只有一只角……对照原文检查；
   - 多余的东西：文字、印章、边框、第二只动物；
   - 朝向不对就水平翻转成朝右。
   存为 `art_src/beasts/<id>/raw.png`。
4. **处理**：
   ```bash
   pip install pillow
   python3 tools/art/prepare_beast.py art_src/beasts/<id>/raw.png <id>
   # 或一次处理所有：python3 tools/art/prepare_beast.py --all
   ```
   脚本会去背景、裁边、缩放到 512×512、脚底贴底边、把颜色压到该异兽的五行色板、加墨线外轮廓，输出 `art/beasts/<id>/body.png`，并生成对照图 `art_src/beasts/<id>/preview.png`。
   - 背景没抠干净：调 `--tolerance`（默认 48，越大抠得越多）；
   - 想借一个五行做点缀：`--accent huo`；
   - 原图自带透明背景会直接保留。
5. **看效果**：打开 Godot，在开局界面点"美术预览"，选中这只异兽，切换待机 / 行走 / 攻击 / 受击 / 死亡看动作，右边是战斗中的实际尺寸。再进一局战斗看整体效果。
6. **剪影测试**：在对照图最右边的战斗尺寸下，能不能一眼认出是谁？认不出就回去改轮廓（更夸张的姿势、更突出的特征）。

**效率预估**：流程熟悉后，一只异兽从生成到进游戏约半天到一天。抢先体验版约需 30 只。

## 3. 现状

目前 `art/` 下还没有任何正式美术，游戏里全部显示灰盒色块。按上面的流程处理好一只，它在游戏里就会自动换成图，其余异兽仍是色块，可以一只一只地替换。

**不要使用 Unity 版留下的 Q 版卡通美术**，它和"古籍刻本"方向不符。

## 4. 常见问题

| 问题 | 办法 |
| --- | --- |
| 每张图风格都不一样 | 固定定调图做风格参考，或训练风格 LoRA；同一批异兽一次性生成 |
| 压色板后颜色发脏 | 原图本身颜色太多太花。提示词里强调 flat colors，或在 Krita 里先手动简化颜色 |
| 缩小后糊成一团 | 姿势不够舒展、特征不够突出。换一张侧面更清楚的，或加粗外轮廓 `--outline 6` |
| 脚底没贴地 | 原图下方有阴影或地面被当成身体。在 Krita 里擦掉地面再处理 |
