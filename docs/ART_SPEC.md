# 美术规格

山海守鼎的美术方向是"古籍刻本 × 青铜拓片"：异兽以明清《山海经》刻本插图为母本，墨线勾勒、少量平涂；界面借青铜器拓片的质感。本文规定交付标准，工作流见 [ART_PIPELINE.md](ART_PIPELINE.md)。

## 1. 风格

| 项 | 要求 |
| --- | --- |
| 线 | 粗细有变化的黑墨线（刻本的刀刻感），外轮廓最粗 |
| 色 | 平涂为主，最多三档明暗；阴影用墨线排线，不用渐变、不用高光反光 |
| 造型 | 照原文形貌，怪而不丑；轮廓要能一眼认出（看剪影就知道是谁） |
| 背景 | 交付时不带背景（透明），不带文字、印章、边框 |
| 禁止 | 写实、3D 渲染、Q 版大头、日系动漫、发光特效画进本体 |

参考来源（公有领域）：明胡文焕本、清汪绂本、清吴任臣《增补绘像山海经广注》等刻本插图。

## 2. 色板

色板的唯一来源是 `tools/art/palette.py`。`python3 tools/art/export_palette.py` 导出 `art_src/shanhai_palette.gpl`（Krita / GIMP 可导入）和 `art_src/shanhai_palette.png`。

| 组 | 颜色 | 用途 |
| --- | --- | --- |
| 纸 | `#efe9dc` `#d8cfbb` | 背景、纸影 |
| 墨 | `#1c2421` `#3b4540` `#6b736e` `#f5f1e8` | 线、暗部、淡墨、高光 |
| 木 | `#1f5a3f` `#2f7d5a` `#7fb595` | 木属异兽 |
| 火 | `#7d2a1d` `#b9402c` `#e08a72` | 火属异兽 |
| 土 | `#7a5a1e` `#b8892e` `#e2c07a` | 土属异兽 |
| 金 | `#8e989d` `#c9d0d4` `#eef1f2` | 金属异兽 |
| 水 | `#1a2735` `#26384d` `#5b7491` | 水属异兽 |
| 青铜 | `#6d5a3a` `#9c6a27` `#c9a25a` `#2f7d6d` | 铜鼎、法宝、界面 |

规则：**五行色只给玩法信息用**。一只异兽主要用自己五行的三档色，最多再借一个五行做点缀（处理脚本的 `--accent`）。这样玩家扫一眼颜色就知道克制关系。

## 3. 异兽图片

| 项 | 要求 |
| --- | --- |
| 文件 | `art/beasts/<beast_id>/body.png`，id 与 `content/beasts/<id>.tres` 一致 |
| 尺寸 | 512×512，PNG，透明背景 |
| 朝向 | **朝右**（游戏里朝左时自动翻转） |
| 视角 | 侧面或略带 3/4 侧面，平视 |
| 落脚 | 脚底贴画布底边、水平居中（游戏以底边中点为落脚点） |
| 外轮廓 | 有一圈墨线外描边（处理脚本默认加 4 像素） |
| 战斗显示 | 杂兵 70、普通 110、精英 140、首领 200、稀有 125 像素高（1080p，见 `scenes/battle/beast_art.gd`） |

**剪影测试**：缩到战斗尺寸（约 110 像素高）后，只看黑色剪影也要认得出是哪只异兽。处理脚本生成的对照图最右边就是战斗尺寸。

**一图两用**：同一张图既用于敌人，也用于守鼎异兽，不需要画两套。

## 4. 动作

现阶段不需要逐帧动画。游戏用程序驱动单张图做出动作（参考皮影戏的简洁动作），见 `scenes/battle/beast_sprite.gd`：

| 动作 | 表现 |
| --- | --- |
| 待机 | 轻微呼吸起伏 |
| 行走 | 上下颠簸、左右微摆 |
| 攻击 | 先后坐蓄力，再朝目标前冲，再回位 |
| 受击 | 闪白、左右抖动 |
| 死亡 | 倒向一侧、下沉、淡出 |
| 定身 / 毒涎 | 叠加蓝色 / 紫色 |

以后要做更细的动作（翅膀扇动、尾巴摆动），把异兽拆成头、身、腿、尾、翅等部件分别交付，再在 Godot 里用 Skeleton2D 绑骨骼。拆件规范到那时再补。

## 5. 道具与界面

| 资源 | 路径 | 说明 |
| --- | --- | --- |
| 铜鼎 | `art/props/ding.png` | 战场终点的鼎，显示高度约 150 像素 |
| 界面 | 待定 | 青铜拓片质感的边框、按钮、图鉴卡片 |

## 6. 目录约定

```
art/                 游戏里用的成品（Godot 会导入）
  beasts/<id>/body.png
  props/ding.png
  shaders/
art_src/             源文件和中间产物（有 .gdignore，Godot 不导入）
  beasts/<id>/raw.png       AI 生成或手绘的原图
  beasts/<id>/preview.png   处理对照图（原图 / 成品 / 战斗尺寸）
  shanhai_palette.gpl       色板
  PROMPTS.md                每只异兽的绘图提示词
```
