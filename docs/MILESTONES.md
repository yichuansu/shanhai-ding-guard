# 里程碑

预制作路线。每一段都要能单独演示或单独评审。数值、最终美术、广告、支付和服务器不提前渗入。

引擎在 M0 锁定。M1 及以后默认按锁定结果实现；下文的「编辑器 / 真机」在 Unity 提案下指 Unity 编辑器与 iOS 或 Android 开发构建。

## M0 Bootstrap

**目标**

仓库能被人读完并接着干活：文档与样例入库；引擎从 PROPOSED 变成书面锁定；后续 PR 提交一个打得开的空工程。

**退出标准**

- 本 PR：`README.md`、`docs/`、`content/examples/`、`tools/`、Unity 向 `.gitignore`、专有 `LICENSE` 已在分支上。
- 开放问题里「微信小游戏」和「首发平台」有书面答案，`docs/TECH_STACK.md` 的状态改为已锁定。
- 后续工程 PR：干净工程能在编辑器中打开，进入一个横屏空场景。不提交 `Library/`。

**范围外**

玩法、正式场景、美术资源、广告、IAP、后端、CI。

## M1 垂直切片

**目标**

一条路径、一座金塔（`tower_jin`）、一种敌人当康（`enemy_dangkang`）、三波、分出胜负、2 倍速桩。用来证明 tick 模拟和内容读取是通的。

**退出标准**

- 关卡数据补全路径点与三波数量后，编辑器内可从开打到结束。
- 三波清空且场上无敌人则胜。失败走关卡上的 `outcome.lose` 规则 id（规则内容由策划表在本里程碑填入，程序不私自加一条生命公式）。
- 倍速可在 1 与 2 之间切换，只改变模拟推进，不改单次伤害。
- 塔与敌人从数据读入。样例 JSON 里的 `null` 在本里程碑被替换成表内数字，或另有一张标明为切片专用的数据，避免改坏「形状样例」的含义时无人知晓。

**范围外**

其余四种五行、相克倍率、英雄、捕获、局外枢纽、合成、广告、支付、服务器。

## M2 五行、相克与四角 UI

**目标**

五座塔对应金木水火土，伤害走全局相克表，横屏 HUD 四角有五行与资源占位。

**退出标准**

- 五种 `element` 都可放置，敌人 `element` 不再为 `null`。
- 相克倍率只来自元素表。表内没有的组合按「中性、不改伤」处理。
- 相生邻接按当时已回答的方向（四向或八向）和加成字段生效，加成幅度来自数据。
- HUD 四角在横屏安全区内可见，允许是占位控件。

**范围外**

合成、英雄技能、捕获、最终图标与动效、完整经济循环。

## M3 可操控英雄

**目标**

哪吒作为桩角色可移动，并有技能按钮把效果送进模拟。

**退出标准**

- 移动方式实现为当时锁定的 `moveMode` 之一种（沿路径、可建造区或固定站位）。未锁定前不做第二套移动。
- 至少一个技能按钮：冷却按 tick 走，效果 id 来自英雄数据，并在下一个 tick 结算。
- 2 倍速下技能不会在表现层单独多触发一次。

**范围外**

完整技能组、动画打磨、捕获、图鉴。

## M4 第一章教程关 1–5

**目标**

冀州第一章 1 到 5 关能按顺序进入。本里程碑以数据和桩场景为主，不要求最终文案。

**退出标准**

- 五个关卡 id 的波次数据可加载，其中一关可以就是补全后的 `level_jizhou_01`。
- 通关一关后，下一关可从本地进度进入。
- 教程步骤是数据或桩 UI，不把正式文案写死在代码里。

**范围外**

其余章节、配音、最终叙事、线上配置。

## M5 捕获与山海经图鉴桩

**目标**

对局内一次捕获，把一只异兽写进本地图鉴，并打开一页图鉴桩。

**退出标准**

- 捕获条件来自数据（条件 id + 参数），模拟只发出解锁意图。
- Meta 把该异兽 id 写入 `shanhaijingUnlocks`，重进游戏仍然解锁。
- 有一页横屏图鉴桩能显示「已解锁 / 未解锁」。

**范围外**

完整图鉴、助手 AI 的完整行为、云同步、分享。

## M6 局外枢纽壳（横屏）

**目标**

横屏局外壳能进入战斗、图鉴桩和设置桩。

**退出标准**

- 从枢纽进入 M4 的关卡入口，再回到枢纽时本地进度还在。
- 设置桩至少能改模拟倍速偏好并写入存档。
- 界面是横屏壳，不含最终视觉。

**范围外**

运营活动、邮件、社交、真实商品目录、广告变现。
